# Pank v2.4.1 Infrastructure

This build adds the shared infrastructure required before Anonymous Q&A and Tickets are implemented.

## Included

- SQLite-backed guild configuration
- `/config` administration command
- Shared permission checks
- Prefix-based button routing
- Prefix-based modal routing
- Reusable confirmation buttons
- Shared interaction response helpers
- Cleaner webhook permission startup logging
- Clearer startup completion logging

## Configuration prepared

- Moderator role
- Tickets category
- Closed Tickets category
- Ticket log channel
- Anonymous Q&A recipient
- Anonymous Q&A identity override role
