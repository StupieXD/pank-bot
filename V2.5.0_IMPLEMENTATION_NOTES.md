# Pank v2.5.0 Implementation Notes

This release preserves the existing command, event, database and interaction-routing architecture introduced in v2.4.1.

## Anonymous Q&A
- Questions are stored in SQLite before delivery.
- The normal recipient view never contains the sender identity.
- Identity reveals are explicit, permission-restricted and audited.
- Lockdown blocks new modal openings and submissions.

## Emergency lockdown
- Saves the explicit @everyone overwrite state for each supported channel.
- Denies sending messages and creating/sending in threads.
- Restores the exact saved states rather than assuming defaults.
- Channels Pank cannot manage are reported as skipped.

## Ticket infrastructure preparation
`/config setup-tickets` creates private Tickets and Closed Tickets categories plus a private ticket-logs channel, stores their IDs and places the categories at the top where possible. The full ticket lifecycle remains scheduled for v2.6.
